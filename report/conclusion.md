# Общий вывод

В ходе практической работы разработано настольное приложение
«Файловый обозреватель» на Electron. Создано окно BrowserWindow,
подготовлен интерфейс и организовано разделение ответственности
между главным процессом, preload-скриптом и процессом отрисовки.

Чтение рабочего каталога выполняется в главном процессе средствами
fs.readdir. Интерфейс получает результаты через ограниченный API
contextBridge и механизм ipcRenderer.invoke / ipcMain.handle.
Для окна включены contextIsolation и sandbox, а прямой доступ
страницы к Node.js отключён.

По варианту 4 реализовано главное меню с пунктом «Обновить список».
Кнопка интерфейса и пункт меню используют одну функцию обновления,
что исключает дублирование логики отображения.

Средствами electron-builder сформирован установщик NSIS
для Windows x64. Его размер составил 112 150 000 байт.
Результат показывает, что небольшой объём прикладного кода
не означает небольшой дистрибутив: вместе с приложением
поставляются компоненты Electron, включая Chromium и Node.js.

Получен практический опыт создания Electron-приложения,
организации IPC, использования системного меню, упаковки
и сопровождения проекта в Git.
