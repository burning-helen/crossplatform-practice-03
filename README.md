## Цель работы

Разработать кросс-платформенное десктопное приложение на Electron,
организовать взаимодействие процессов через preload и IPC,
реализовать индивидуальную функцию и собрать дистрибутив для Windows.

## Приложение

Файловый обозреватель с выводом содержимого рабочего каталога.

Индивидуальная функция: главное меню приложения с пунктом
«Обновить список», повторно запускающим чтение каталога.

## Запуск

Установка зависимостей:

npm ci

Запуск приложения:

npm start

## Реализованные возможности

- Просмотр содержимого рабочего каталога.
- Выделение каталогов в списке.
- Сортировка: сначала каталоги, затем остальные записи.
- Обновление по кнопке и через главное меню.
- Обработка ошибок чтения.
- Ограниченный доступ к системным операциям через preload и IPC.
- Сборка установщика NSIS для Windows x64.
