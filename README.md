# Практическая работа № 3

Тема: «Практикум работы с фреймворком Electron»

Группа: ТРПО23-1
Вариант: 4

## Цель работы

Разработать кросс-платформенное десктопное приложение на Electron,
организовать взаимодействие процессов через preload и IPC,
реализовать индивидуальную функцию и собрать дистрибутив для Windows.

## Приложение

Файловый обозреватель с выводом содержимого рабочего каталога.

Индивидуальная функция: главное меню приложения с пунктом
«Обновить список», повторно запускающим чтение каталога.

## Запуск

Установка зависимостей:

npm ci

Запуск приложения:

npm start

## Статус

Проект инициализирован. Реализация приложения выполняется
в следующих заданиях практической работы.
